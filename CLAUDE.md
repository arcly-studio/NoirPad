# CLAUDE.md – NoirPad

Local notes app: FastAPI backend (`noirpad/`), vanilla-JS frontend (`static/`), desktop shell
`desktop.py` (WebView2), web variant `NoirPad-web.py`.

## Commands
- Python tests: `.venv\Scripts\python.exe -m pytest` (deps: `requirements-dev.txt`).
- JS tests: `npx vitest run` (`npm test`; tests in `tests/js`).
- Build: `build.ps1` (refuses to run unless `git status` is clean; see `BUILD.md`).
- **No bundler**: `static/` is served as-is. Edit and reload.
- Vendor files (fonts, markdown-it, DOMPurify, highlight.js, icons) are generated from
  `node_modules` with `npm run vendor` (`tools/vendor.mjs`). Never hand-edit `static/vendor/`.

## UI structure (`static/index.html`)
- Top bar `#top-bar`: `#top-bar-title`, `#tab-bar` (tabs, `static/js/tabs.js`), `#top-tools`
  (icon buttons). `static/js/topbar.js` holds `NP.icon`, `NP.menu` (shared popup menu), the
  Export and ⋯ menus (incl. `md_split` toggle).
- Sidebar: `#sidebar-search` opens find-all (`find-all.js`, Ctrl+Shift+K); NOTES / TAGS sections;
  `tree.js` = tag filter (`NP.tree.tagFilter`), ARIA tree with keyboard, context menu with
  rename / "Move to…" (`_openMoveMenu`) / delete.
- Note header `#note-header`: `#note-title-row` (rename in place -> `NP.app.renameNote`) and
  `#tag-bar` (rendered by `tags.js`).
- Editor / preview have no frames. Status bar: `#status-label` (● saved / ○ not saved, driven by
  `NP.editor._setSaveStatus` / `_renderStatus` in `editor.js`), `#mode-label`, counts.

## Icons
- Lucide (`lucide-static`, ISC; Feather-derived icons MIT – both in
  `static/vendor/lucide/LICENSE`). Sprite `static/vendor/lucide/sprite.svg` is generated by
  `tools/vendor.mjs` from its `ICONS` list.
- Add an icon: add the name to `ICONS`, run `npm run vendor`, then use `NP.icon("name")` or
  `<svg class="np-icon"><use href="/static/vendor/lucide/sprite.svg#i-name"></use></svg>`.
- `tests/test_icons.py` fails if a used icon is missing from the sprite.

## Noir effects (glow, Matrix rain, CRT)
- Data keys `glow_enabled`, `matrix_rain_enabled`, `crt_enabled`; all `False` in
  `noirpad/storage.py` `DEFAULT_DATA` (also in `models.py`).
- One-time migration for pre-redesign data: `_migrate_noir_effects` -> `_noir_effects_upgrade`
  (keeps old look: glow on, rain unless explicitly off). `glow_enabled` present = already done.
  Also applied to a snapshot restored after a damaged data file.
- Frontend: `settings.js` `effects()`, `applyEffects()`, `setEffects({glow,matrix,crt})`;
  `effects.js` and `matrix-rain.js` call `setEffects`. CRT used to live in localStorage
  (`migrateCrt` moves it).
- CSS: `body:not(.np-glow) * { text-shadow: none !important }` (top of `noirpad.css`); glow
  variables are set to 0 while effects are off. Do not add text-shadow outside this rule's reach.

## Design tokens / theming
- `static/css/themes.css` (17 themes). Tokens added in the redesign: `--font-brand`, `--bg-panel`,
  `--folder-color`, `--code-bg`, `--accent-soft`, `--danger`. Use tokens, not hard-coded colours.
- `tests/test_contrast.py` checks all 17 themes: text >= 4.5:1, icons / muted >= 3:1. Run it after
  touching any theme colour.
- The shared window style (dialogs, menus, popups) is the block "G7" at the end of `noirpad.css`.
  Reuse it for new windows.

## Conventions
- i18n: every visible text via `NP.t(...)` or `data-i18n*` attributes; keys in
  `static/locales/en.json` and `cs.json` (identical key sets, both updated together).
- Build DOM with `textContent` / DOM APIs. Never `innerHTML` with user data.
- Commit messages in Czech, with a `Co-Authored-By` line.
- Tests/manual checks only in your own instance with a temporary `NOIRPAD_DATA_DIR`. Never touch
  the user's running NoirPad, their data, the clipboard or their other apps.
- Windows: use absolute paths; PowerShell is the primary shell.
